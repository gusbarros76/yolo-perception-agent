# Roadmap

## MVP
- Solidify detection event schema and API contract.
- Implement basic perception endpoints (request/response shape only).
- Add minimal web UI for upload and result viewing.
- Establish local dev workflow for API and web services.
- Expand architecture and integration documentation.

## Post-MVP
- Integrate YOLO inference with model management.
- Add streaming/webcam ingestion and real-time visualization.
- Provide persistence for events and media artifacts.
- Add authentication, authorization, and rate limiting.
- Add monitoring, metrics, and tracing for production readiness.
